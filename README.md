Проект: OOP КАЛКУЛАТОР (на C++)

Описание:

Това е обектно-ориентиран калкулатор, написан на C++, който поддържа както базови аритметични операции, така и по-напреднали математически функции. Включва операциите:

Събиране, изваждане, умножение, деление

Степенуване (^), корен квадратен (r), модулно деление (%)

Факториел (!), логаритъм (log), натурален логаритъм (ln)

Тригонометрични функции: синус (sin), косинус (cos), тангенс (tan)

Програмата е интерактивна – потребителят въвежда първо число, избира операция, и ако е необходимо, въвежда второ число. Изписва резултата и позволява нова операция до въвеждане на end

За да стартираме калкулатора трябва да отворим a.exe.
